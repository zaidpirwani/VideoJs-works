PSL video player - layout options

Demo for devs. Native <video> plus about 250 lines of vanilla JS/CSS. No library, no gradient. Options B-F put the controls below the video, so the bar never covers the signer's hands or face.

A

Native controls, gradient removed

Current tag with CSS only: ::-webkit-media-controls-panel { background-image: none }. Left: transparent. Right: flat solid bar.

Pros
  • Zero JS, one CSS rule
  • Browser handles accessibility
Cons
  • Chrome/Edge/Safari only - Firefox keeps its own look
  • Controls stay ON the video; cannot move below
  • No custom buttons (loop, mirror, 0.25x)
B

Single-row bar below (dark)

Classic layout: play, time, seek, volume, speed, loop, PiP, fullscreen in one row under the video.

Pros
  • Familiar, compact (48px)
  • Full video always visible
Cons
  • Seek bar gets short on mobile
C

Stacked bar below (light)

Full-width seek row on top, buttons row under it. Light theme to sit on a white page.

Pros
  • Long seek bar at all widths
  • Room for loop, mirror, captions, back 2s
Cons
  • Taller (about 90px)
D

Seam progress

Thin progress line sits on the edge between video and bar. Minimal single row of buttons.

Pros
  • Clean, modern, compact
  • Seek line is full width
Cons
  • Thin seek target - grows on hover only
E

Overlay, no gradient (comparison)

Controls on the video like the default, but no gradient. Icons get a drop shadow. Bar auto-hides after 2.5s while playing.

Pros
  • No extra height
Cons
  • Covers the bottom of the frame - signer's hands
  • Low contrast on bright video
F

Learn mode - sign practice toolbar

For dictionary and lesson clips. Speed chips (0.25x to 1x), loop, mirror (practise as in a mirror), back 2s, captions. Bigger 44px targets.

Pros
  • Learner tools visible, one tap each
  • Audio controls de-emphasized
Cons
  • Tallest option (about 140px)
  • Mirror flips burned-in text too

Usage

<link rel="stylesheet" href="psl-player.css">
<div class="psl-player psl--learn" data-layout="learn">
  <video src="sign.mp4" poster="sign.jpg" preload="metadata">
    <track kind="captions" src="sign.vtt" srclang="en" label="English">
  </video>
</div>
<script src="psl-player.js"></script>
<script>PslPlayer.initAll();</script>

Layouts: bar, stacked, seam, overlay, learn. Add the matching psl--* class. Theme via CSS variables --psl-accent, --psl-bar-bg, --psl-fg. Edit LAYOUTS in the JS to reorder buttons.
